
# 📱 Digital Addiction Risk Predictor

## Project Overview
A Machine Learning project using Logistic Regression
to analyze smartphone usage patterns and estimate
the risk of excessive smartphone usage.

🔗 Submission Link
Clickable Submission Link: https://github.com/complexiota

## Features
- Daily screen time analysis
- Night-time usage analysis
- App session analysis
- Social media usage analysis
- Binary classification
- Probability-based prediction
- Interactive decision threshold
- Confusion matrix
- ROC-AUC evaluation
- L1 and L2 regularization comparison

## Machine Learning Algorithm
Logistic Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Evaluation
- Accuracy
- Precision
- Recall
- Specificity
- F1-score
- ROC-AUC
- Log Loss

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Train the model:

   python train_model.py

3. Launch the application:

   streamlit run app.py

## Dataset
Publicly available smartphone usage dataset.
See the dataset source and original label definitions
for details.

## Disclaimer
This is an educational machine-learning project.
It does not provide a clinical diagnosis of addiction.
